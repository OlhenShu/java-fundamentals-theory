Теоретичний конспект курсу Java Fundamentals

Тут зібрана теорія курсу: пояснення, приклади й перевірки, розкладені по темах. Кожна тема — окрема сторінка, на яку можна перейти зі списку нижче.

Матеріал розрахований на JDK 25. Нові теми з’являтимуться в цьому списку, щойно для них буде сторінка.

Теми

  1. 01

    Java Introduction

    Від текстового файлу до працюючої програми: що встановити, як Java знаходить точку входу, які бувають типи даних і навіщо класам пакети.

    Відкрити тему
  2. 02

    Control version with Git and GitHub

    Як працює Git, як створювати репозиторій, як робити коміти, як публікувати репозиторій на GitHub, як працювати з віддаленим репозиторієм.

    Відкрити тему
  3. 03

    Вступ до ООП: класи та об'єкти

    Як описати власний тип даних, захистити його стан від некоректних змін і зібрати поведінку поруч із даними, з якими вона працює.
